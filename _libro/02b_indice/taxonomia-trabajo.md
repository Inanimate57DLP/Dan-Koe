# Taxonomía de trabajo para la Fase 2 (etiquetado temático provisional)

Códigos de tema. Cada unidad recibe UN tema principal (y opcionalmente uno secundario).

| Código | Tema |
|---|---|
| T01 | La Matrix, condicionamiento, programación, NPC, crítica a la sociedad/escuela/empleo, consciencia (awareness), apertura mental |
| T02 | Identidad, conceptual survival, ego, mental body, niveles de mente/desarrollo (ego development, Human 3.0, Wilber, Spiral Dynamics), cómo cambia (o no) una persona, reinvención |
| T03 | Visión, anti-visión, jerarquía de metas, propósito, proyectos con sentido, la vida como videojuego, flow, desafío/habilidad |
| T04 | Entropía, psychic entropy, orden de la consciencia, la mente como sistema (cibernética, metas como dirección) |
| T05 | Enfoque y deep work: 4-hour workday, bloques de tiempo, deadlines, Koe's Law, prioridades, ciclos de progreso, descanso, caminar, rutinas diarias, productividad minimalista |
| T06 | Dopamina (barata vs significativa), distracción, disciplina, diseño del entorno, monk mode, detox, hábitos |
| T07 | Aprendizaje: adquirir habilidades rápido, aprender construyendo, tutorial hell, lectura, notas/second brain, inteligencia, IA para aprender, prompts |
| T08 | Pensamiento: estratégico, original, síntesis, creatividad, escepticismo, articulación, niveles/dimensiones de pensamiento |
| T09 | Escritura y creación de contenido: la escritura como habilidad base, ideas, estructuras/frameworks de posts, hooks, ensayos, ecosistema de contenido, repurposing |
| T10 | Audiencia y distribución: crecer desde cero, redes sociales, plataformas, networking, marca personal, confianza, leverage de distribución, muerte de las redes/marca personal |
| T11 | Nicho: "you are the niche", niche of one, personal/mental monopoly, múltiples intereses, generalista vs especialista |
| T12 | Modelo de negocio de una persona: definición, pilares (brand/content/product/marketing), roadmap y etapas, MVO, servicio → producto, cuánto ganar/umbrales |
| T13 | Productos, ofertas y ventas: info-productos, micro educación, productizar, landing pages, copywriting, persuasión, niveles de awareness, promociones, precios |
| T14 | Nueva economía y futuro del trabajo: value creator, creator economy, IA y automatización, skill stacks, habilidades de alto ingreso, meaning economy, renacimiento digital |
| T15 | Dinero, riqueza, leverage, wage slavery, emprendimiento como supervivencia, agencia, libertad de tiempo |
| T16 | Filosofía de vida y bienestar: felicidad, dificultad/sufrimiento, sentirse perdido, los 20s, salud y cuerpo, relaciones, estilo de vida, espiritualidad, sentido de la vida |
| T17 | Biografía y casos del autor: su historia, negocios fallidos, cifras de ingresos, sus productos (Kortex/Eden, 2 Hour Writer...) |
| T18 | Construir startups y equipos (Stan, Kortex): contratación, cultura, product-market fit |

Los aportes de invitados (Justin Welsh, Sahil Bloom, Dickie Bush, Devon Eriksen, fundadores de Stan) se etiquetan por TEMA, no por invitado; su atribución se conserva en el campo origen.
